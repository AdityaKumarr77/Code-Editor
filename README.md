# Aditya Editor

Online code editor built with React, Vite and TypeScript, powered by Monaco (the VS Code editor).

## Run
```
npm install
npm run dev
```
Build for production: `npm run build`

## Features
- Languages: JavaScript, TypeScript, HTML, CSS, Python, C++, Java, JSON
- Run JavaScript, TypeScript and HTML in a sandboxed iframe (Ctrl/Cmd + Enter)
- Console output with log, warn and error colors
- Dark and light themes, font size controls, download file, reset to sample
- Code is saved per language in your browser

Monaco loads from a CDN, so the editor needs an internet connection.
